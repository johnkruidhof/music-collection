Importeren uit Discogs

Exporteer op Discogs je collectie (Collection → Export) en kies hier het CSV-bestand. De gegevens worden per release bij Discogs opgehaald; dat duurt ongeveer een seconde per release. Opnieuw importeren is veilig: releases die je al hebt worden overgeslagen.
